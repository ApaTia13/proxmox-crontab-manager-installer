# Proxmox Crontab Manager Installer

Автоматический установщик для [**Proxmox Crontab Manager**](https://github.com/ApaTia13/bash-proxmox-crontab-manager) – интерактивного Bash-менеджера задач cron для виртуальных машин и контейнеров Proxmox.

Скрипт создаёт выделенного пользователя `proxmox-scheduler`, настраивает sudo-права, загружает выбранную версию менеджера, подготавливает окружение и опционально добавляет alias для быстрого запуска. Идеально для быстрого развёртывания без ручной возни.

## Возможности установщика

- 📥 **Выбор версии** – загружает список релизов с GitHub и позволяет выбрать нужную (1.0.0, 1.1.0 и т.д.).
- 👤 **Создание пользователя** – автоматически создаёт пользователя `proxmox-scheduler` (если не существует) и запрашивает пароль.
- 🔧 **Настройка sudo** – добавляет правила для выполнения команд `qm` и `pct` без пароля (через `/etc/sudoers.d/`).
- 🌐 **Установка curl** – при необходимости предлагает установить curl (для уведомлений Telegram) с подтверждением.
- 📂 **Подготовка директорий** – создаёт `/home/proxmox-scheduler/proxcron` и выставляет правильные права (750).
- ⬇️ **Загрузка скрипта** – скачивает выбранную версию `proxcron.sh` с GitHub с обработкой ошибок и редиректов.
- 🚀 **Alias** – опционально добавляет команду `proxcron` в `.bash_aliases` для быстрого запуска.
- ▶️ **Автозапуск** – после установки может сразу переключиться на пользователя и запустить менеджер.

## Как это работает (пошагово)

1. Установщик получает список доступных релизов через GitHub API.
2. Пользователь выбирает версию для установки.
3. Создаётся пользователь `proxmox-scheduler` (если нужно) и запрашивается пароль.
4. При отсутствии curl выводится запрос на установку.
5. Создаётся директория `/home/proxmox-scheduler/proxcron`.
6. С выбранного релиза скачивается файл `proxcron.sh` и помещается в эту директорию.
7. Настраиваются sudo-права для команд управления Proxmox.
8. Опционально добавляется alias.
9. Выводятся инструкции и предлагается сразу запустить менеджер.

## Требования

- Хост Proxmox (версия 6.x, 7.x или 8.x).
- Права root или возможность использовать sudo.
- Доступ в интернет для загрузки скрипта и получения списка релизов.
- `curl` или `wget` (один из них должен быть установлен; если нет – скрипт предложит установить curl).

## Установка установщика

Скопируйте скрипт на сервер Proxmox и сделайте его исполняемым:

```bash
wget -O proxcron-autoinstall.sh https://github.com/ApaTia13/proxmox-crontab-manager-installer/releases/download/1.0/proxcron-autoinstall.sh
chmod +x proxcron-autoinstall.sh
```

## Использование
Запустите скрипт от root или через sudo
```bash
sudo ./proxcron-autoinstall.sh
```
Далее следуйте интерактивным подсказкам:

1. **Выберите версию Proxmox Crontab Manager из списка.**  
   Установщик покажет пронумерованный список доступных релизов (например, `1.0.0`, `1.1.0`). Введите номер нужной версии и нажмите Enter.

2. **Подтвердите установку.**  
   Скрипт выведет список действий, которые будут выполнены (создание пользователя, настройка sudo, загрузка скрипта и т.д.). Введите `y` для продолжения или `n` для отмены.

3. **При необходимости разрешите установку curl.**  
   Если на сервере не обнаружен `curl`, установщик спросит, хотите ли вы его установить (требуется для отправки уведомлений в Telegram).  
   - Введите `y`, чтобы установить `curl` через `apt`.  
   - Введите `n`, чтобы пропустить установку – уведомления Telegram будут недоступны, но остальной функционал сохранится.

4. **Задайте пароль для пользователя `proxmox-scheduler`.**  
   Система запросит новый пароль (ввод скрыт). Введите пароль дважды для подтверждения. Этот пароль потребуется для интерактивного входа в систему под этим пользователем.

5. **Дождитесь завершения установки.**  
   Скрипт создаст директорию `/home/proxmox-scheduler/proxcron`, загрузит выбранную версию менеджера, настроит sudo-права и предложит добавить alias.

6. **Добавьте alias (опционально).**  
   Установщик спросит, хотите ли вы добавить команду `proxcron` для быстрого запуска.  
   - При согласии alias будет прописан в `~/.bash_aliases` пользователя `proxmox-scheduler`. Чтобы он заработал, выполните `source ~/.bash_aliases` или перелогиньтесь.

7. **Запустите менеджер сразу (опционально).**  
   После завершения установки скрипт предложит переключиться на пользователя `proxmox-scheduler` и запустить менеджер. При согласии вы попадёте в интерактивное меню Proxmox Crontab Manager.

Все действия, требующие прав root, выполняются автоматически через `sudo` (если скрипт запущен не от root). Установка завершается выводом итоговой информации и инструкций по ручному запуску.

## Что будет после установки

| Компонент               | Расположение                                  |
|-------------------------|-----------------------------------------------|
| Основной скрипт         | `/home/proxmox-scheduler/proxcron/proxcron.sh` |
| Обёртка для cron        | Будет создана при первом запуске менеджера в той же папке |
| Логи                    | `/home/proxmox-scheduler/proxcron/logs/`      |
| Бэкапы crontab          | `/home/proxmox-scheduler/.cron.backups/`      |
| Конфиг Telegram         | `/home/proxmox-scheduler/.proxcron.conf`      |
| Alias (опционально)     | `/home/proxmox-scheduler/.bash_aliases`       |

## Примечания

- Если пользователь `proxmox-scheduler` уже существует, установщик не будет его пересоздавать, но пароль запросит в любом случае.
- Установка curl происходит только после явного согласия пользователя.
- При ошибке скачивания скрипта (например, проблемы с сетью) установка прерывается.
- Все действия, требующие прав root, выполняются через `sudo` или напрямую, если скрипт запущен от root.
